# 智程 UniPlan

面向学生及职场人士的 AI 时间规划系统，围绕目标管理、任务拆解、确定性排程、执行反馈与动态调整，构建从目标设定到计划执行的完整管理流程。

本项目为软件工程课程小组复现项目。当前仓库仅上传课程需求文档，产品源码、数据库迁移、运行配置和测试材料将在后续阶段补充。
